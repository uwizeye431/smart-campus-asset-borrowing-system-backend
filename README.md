Steps to run the API

1. I installed Java, Maven and PostgreSQL in my machine. And created my project folder using spring initialzr

2. Then i created a PostgreSQL database named smart_campus_asset_borrowing_system_db.

3. Opened the file src/main/resources/application.properties and updated the username and password to match my PostgreSQL credentials.

4.  Run this command: mvn spring-boot:run in terminal to run the project

5. The API will start on port 8082. I tested it using Postman by importing the file smart-campus-asset-borrowing-system-midterm.postman_collection.json.
